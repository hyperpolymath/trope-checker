== Modelling notes

Faithful-but-simplified choices, recorded for honesty:

* *Provenance tags on `Fused` are erased* in the verified core (they are metadata
  that does not affect the lattice laws); the executable checker carries them.
* *Deceptive duals are modelled as each coordinate's bottom* (worst retention,
  absorbing), which is how the calculus orders `Conflated`; this makes every
  honest floor fail against a deceptive grade (HC-2) by construction.
* *L2 is stated with stem:[\varepsilon]'s literal value* in Idris (a bare top-level
  `epsilon` as a function argument does not reduce under the unifier); since
  `epsilon = MkGrade Present Present Present Present Intact Single`
  definitionally, the statement is stem:[\varepsilon \triangleright g = g].
* *The use-model floor is a partial per-coordinate demand, not a grade value.*
  HC-4 (the Σ-coherence: bond⊣bearer-fate) is enforced on edge grade VALUES, where
  it makes incoherent states unrepresentable; the floor is a set of independent
  minimum-demands (each coordinate optional), so an author CAN write an incoherent
  floor (e.g. bearer-Dropped + bond-Intact). This is harmless — each demanded
  coordinate is checked independently — but is an author-error surface, not
  covered by the HC-4 unrepresentability claim. (Audit 2026-06-22.)
