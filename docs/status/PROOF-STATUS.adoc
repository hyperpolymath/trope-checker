== Proof Witness Grades

Estate policy
link:https://github.com/metadatastician/standards/blob/main/3-practice/PROOF-POLICY.adoc[`PROOF-POLICY.adoc`]
§8 (owner ruling 2026-11-04) requires each *theory* theorem's Proof Witness
Grade to be recorded in its home repository's proof-status file (§8.5). This
section is that record. PWG counts independent machine-checked witnesses for a
theory theorem; *lower is stronger* (§8, the numbers count down). It is not a
status token (§5) and not a statement that the theorem complies with the policy
(§8.4 rule 1).

The evidence lives in `verification/pwg.json`: per obligation, each leg's route,
its §5 token, its §2.2 correspondence state and its receipts. **No grade is
written there.** §8.4 rule 2 says a grade is computed from the receipts and the
§2.2 records, and that "a grade written by hand that the receipts do not support
is drift" — so `scripts/pwg-derive.sh` is the only thing that turns evidence into
a grade, and `scripts/pwg-check.sh` re-derives on every run and fails if this
table, or the census below, is not what the evidence yields. A `pwg` key in the
ledger is itself a gate failure.

Per §8.1 the ladder covers theory obligations only. The Idris2 developments are
engineering restatements: the ledger records them under `reference`, never as a
leg, so they can neither raise nor lower a grade.

provers. A missing Agda source and a partial one are different debts, and the

== Modelling notes

Faithful-but-simplified choices, recorded for honesty:

* *Provenance tags on `Fused` are erased* in the verified core (they are metadata
  that does not affect the lattice laws); the executable checker carries them.
* *Deceptive duals are modelled as each coordinate's bottom* (worst retention,
  absorbing), which is how the calculus orders `Conflated`; this makes every
  honest floor fail against a deceptive grade (HC-2) by construction.
* *L2 is stated with stem:[\varepsilon]'s literal value* in Idris (a bare top-level
  `epsilon` as a function argument does not reduce under the unifier); since
  `epsilon = MkGrade Present Present Present Present Intact Single`
  definitionally, the statement is stem:[\varepsilon \triangleright g = g].
* *The use-model floor is a partial per-coordinate demand, not a grade value.*
  HC-4 (the Σ-coherence: bond⊣bearer-fate) is enforced on edge grade VALUES, where
  it makes incoherent states unrepresentable; the floor is a set of independent
  minimum-demands (each coordinate optional), so an author CAN write an incoherent
  floor (e.g. bearer-Dropped + bond-Intact). This is harmless — each demanded
  coordinate is checked independently — but is an author-error surface, not
  covered by the HC-4 unrepresentability claim. (Audit 2026-06-22.)
