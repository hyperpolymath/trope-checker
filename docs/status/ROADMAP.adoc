= Trope-checker Roadmap

== Current status

Alpha. The schema, the Idris2 reference checker, the Rust fast core and the
conformance suite are green; the verified developments carry no `sorryAx` and no user
axiom behind their claimed lemmas. Spec v0.2 is the normative document; what is proved and
what is open: `docs/status/PROOF-STATUS.adoc`, `AFFIRMATION.adoc`,
`spec/calculus.adoc §10`.

== Shipped (v0.1)

* [x] Normative calculus (`spec/calculus.adoc`) + Trope IR spec + JSON Schema (the trust boundary).
* [x] Executable checker (Idris2) reusing the verified core; conformance suite green (10/10).
* [x] Verified core (Idris2): L1/L2/⊑ decidability, Veridicality, Honest Generation — no axioms.
* [x] Soundness advance: ⊑-preorder, verdict-soundness corollary, T-Sub soundness, grade
  soundness for *exact* faithful lowering (machine-checked).

== Shipped (v0.2)

* [x] Ratified carrier (ADR 0004, R-2026-07-07): two-sided deceptive zeros (A1), the fate
  chain (A2), `Attenuated(0)` normalisation at ingest (A3); IR 0.2 semantics.
* [x] Agda Theorem B migrated to the ratified carrier (`--safe --without-K`, zero postulates):
  Targets 1, 2, 4 proved; Target 3 β/let proved.
* [x] L4 monotonicity in full, both arguments, every coordinate (Idris2, Lean, Agda); L6
  commutativity.
* [x] Atom factorisation — O1-carrier proved (`EffectAtoms.lean`): nine atom families.
* [x] Tier-2 cancellation membership exhaustive (`TierTwoComplete.lean`).
* [x] Tropical factorisation re-run on the ratified carrier: (B′) factors and
  veridicality-sighted (`GradeFactorisationR.lean`).
* [x] Spec consolidated at v0.2: one normative document on the ratified carrier; O5 defined,
  O6 opened; prover roles per ADR 0005 (Proposed).

== Open problems

The authoritative list is `spec/calculus.adoc §10` — O1-coord, O2, O3, O5 mechanisation,
O6, CO-1 mechanisation — each with its status word; `docs/status/PROOF-STATUS.adoc` "Open"
restates it with where each is specified. CO-1 mechanisation (Agda, steps 1–5 of
`spec/notes/2026-07-07-co1-operational-model.adoc §6`) is the next proof work; it closes
Theorem B Target 3 and conservative grade soundness.

== Deferred

* Full Haec compiler / codegen / runtime (the `haec` repo).
* Rust fast-core hardening (fuzzing, perf); it already agrees with the Idris2 reference over
  the conformance corpus (`just trope-rust`).
* Filing the panic-attack signed-suppression proposal (`docs/proposals/`) upstream.
