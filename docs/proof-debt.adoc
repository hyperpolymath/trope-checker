== Standing position

* No escape hatch is admitted into the trusted base. The verified Idris2 core, the
  Lean grade-algebra ground truth, and the Agda metatheory are all axiom-clean for
  their claimed lemmas.
* The convention comments are retained deliberately: they document the prohibition
  at the point of work. The *root* fix for the scanner mismatch is to make
  `check-trusted-base.sh` comment-aware upstream in `hyperpolymath/standards`
  (solutions-at-source); this ledger records the local ground truth in the
  meantime.
* Should a genuine escape hatch ever be introduced, it MUST be added here under
  class (a), (b), or (c) with its justification before the proof is accepted.

== Addendum (2026-10-28)

The six Idris2 rows above cite files (`verification/proofs/idris2/Types.idr`,
`verification/proofs/idris2/ABI/*`) that no longer exist: they were
uninstantiated template mint files, deleted for the same reason PR #102's T5
deleted the Coq/TLA+/Agda templates (no package built them; PR #102 records
they did not typecheck). Neither Lean audit heading currently matches
`\bsorry\b`: both now use `sorryAx-free`. The current false-positive count is
therefore 0. This ledger's summary claim is unchanged: net
soundness-relevant escape hatches remain 0, now additionally enforced by the
comment-aware banned-construct gate over all Idris2 trees in CI.
