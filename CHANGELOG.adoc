* *A receipt that records FAILURE no longer supports a grade (2026-11-16).*
`+scripts/pwg-derive.sh+` read a receipt's `+state+` but never its `+result+`.
Measured against `+main+` `+0dceab6+`: flipping this repository's Agda receipt to
`+"result": "fail"+` while leaving `+"state": "current"+` left the derived census
*byte-identical* — 17 `+PWG-3+` grades still published on a receipt recording the
checker *rejecting* the development — and `+scripts/pwg-check.sh+` exited `+0+`.
A grade may not outlive the run that earned it; a regressed run is §8.2 evidence
of the opposite. `+usable_receipt+` and `+pwg3_receipt+` now both require
`+result == "pass"+`, and rule 3 constrains `+result+` to the closed vocabulary
`+pass|fail+` so an unrecognised value is an error rather than a silent
non-pass. With the fix the same planted receipt collapses the census to
`+PWG-3+` 0, `+ungraded+` 24. Canaries 20 and 21 plant exactly these two cases
and were confirmed to FAIL against the pre-fix scripts. Canary 22 plants a
`+result+` of `+"pass\n"+`: jq's `+$+` anchor matches before a final newline, so
the rule-3 check admitted it. Rule 3 now compares `+result+` by exact equality.
+
The same defect sat in the seven sibling anchors: the commit check in rule 3
and in both derivation predicates, and the `+state+`, token, §2.2-state and route
vocabularies. Measured: a 40-hex commit followed by a newline passed the *whole*
gate, derivation included, so a malformed provenance field could carry a grade.
All seven are now anchored with `+\A…\z+`. Canaries 23 and 24 plant a trailing newline on a
commit and on a token; both FAIL against the pre-fix scripts and PASS against
the fix. The suite is now *24/24*.
+
Two things this change did *not* do are worth recording, because each was tried
and rejected on evidence. The ShellCheck `+SC1112+` warning on `+pwg-derive.sh+`
could not be fixed the obvious way: that comment sits inside the single-quoted
`+jq+` program, so replacing the Unicode right-quote with a plain apostrophe
*terminated the string* and broke the script — caught immediately by the suite's
own live-ledger canary. The comment is reworded to contain no apostrophe at all,
and the block now carries a warning saying why. And `+SC2030+`/`+SC2031+` were
not silenced: the meta-canary shadowed `+PASS+`/`+FAIL+` inside a command
substitution to discard the probe's deliberate failure, which tainted *ten*
later reads of the real counters. It now reads the probe's verdict line instead,
so the warnings go away by construction rather than by suppression.
`+shellcheck 0.11.0 --severity=style+` — the version and severity CI pins — is
clean over every tracked `+*.sh+`, with no disable added.

* *A comment marker inside a string literal is no longer read as a comment
(2026-11-09).* `+tests/lib/strip-proof-comments.awk+` tracked block comments with
no notion of string literals, so `+def m : String := "/-"+` opened a block
comment that swallowed the rest of the file — and awk still exited `+0+`. An
`+axiom+` declared after such a line was invisible to *every* gate that scans
through the stripper. Measured: three shapes reproduce it (`+"/-"+`, the raw
string `+r"/-"+`, and the hash-delimited `+r#"/-"#+`), and the swallow reached
five call sites, two of them in CI — `+proofs.yml+`'s `+lean-source-honesty+` job
(which exited `+0+` on a planted tree) and its `+declared-axioms+` extraction,
which produced an EMPTY list and so fed the deep axiom audit's own
"never excused" guard with nothing.
+
Strings are now consumed as units and emitted as `+""+`, which also means a
string whose *content* is the word `+sorry+` can no longer trip the gate. Char
literals are skipped whole, guarded so that primed identifiers (`+h'+`, `+n'+`)
are untouched — that clause is load-bearing, not cosmetic: without it the
`+'"'+` in `+src/idris2/Checker/Json.idr+` opens a string and re-creates the hole
in a different file. An unterminated comment or string is now a loud `+exit 1+`:
a truncated scan must never be reported as a clean one. `+tests/aspect_tests.sh+`
had one `+|| true+` covering the whole pipeline, which would have swallowed that
exit; it now covers the `+find+` and the `+grep+` (no match is the good case) but
never the awk.
+
Verified: all three exploit shapes now expose the `+axiom+`; the eight real
Lean proof files produce byte-identical stripper output; 38 scanned files produce
no new failure; `+Admitted+` planted behind a string is caught where it was
previously hidden. Lean 4's *nested* block comments are a known remaining
limitation, recorded in the file — that direction fails loudly, not open, so it
is a separable change.

* *The PWG record is now derived from an evidence ledger, and gated
(2026-11-09).* Owner ruling: a machine-readable ledger rather than prose rows.
`+verification/pwg.json+` holds evidence only — per obligation, each leg's route,
its §5 token, its §2.2 correspondence state and its receipts — and *no grade*.
`+scripts/pwg-derive.sh+` is the only thing that turns evidence into a grade,
implementing §8.1–§8.3 clause by clause; `+scripts/pwg-check.sh+` re-derives on
every run and fails if the published table or census is not what the evidence
yields. A `+pwg+` key in the ledger is itself a gate failure, which is how
§8.4 rule 2 ("grades are derived, not asserted") becomes enforceable rather than
aspirational.
+
The record is now per *obligation* rather than two coarse groups, and the picture
is far more informative: of 24 theory obligations, **17 are `+PWG-3+`** and 7 are
`+ungraded+` — and the seven split three ways. *Two* are Lean-only with no Agda
source at all (the O1 atom factorisation and the tropical (B′) sighting).
*Three* are Idris2-only, where an engineering restatement is not a leg (§8.1).
*Two* have a real but partial Agda leg, so the Agda token is `+OPEN+`: the
retention order, whose Agda leg proves reflexivity but neither transitivity nor
decidability, and tier-2 membership, where `+TB.Tier+` states six of the
per-element non-cancellativity witnesses and the positive `+Q-cancelʳ+` but not
the exhaustive characterisation — there is no Agda counterpart of
`+grade_leftCancel_iff+` and no Agda witness on the merge coordinate. A missing
Agda source and a partial one are different debts. Verdict soundness is
reclassified engineering, so §8.1 puts it off the ladder entirely.
+
Wired: `+just pwg+` (census and per-obligation grades), `+just pwg-render+`
(regenerates the table between the `+PWG-TABLE+` markers, verified idempotent),
`+just pwg-check+`, the gate inside `+just verify-all+`, and a `+pwg-record+`
job in `+proofs.yml+` that needs no prover because the kernels already ran.
+
Falsified, not assumed: `+scripts/test-gate-falsifiability.sh+` gains seven PWG
canaries plus a control, taking the suite to 18 cases at that point (it stands at
*24/24* after the later entries in this same block). Two are load-bearing —
removing the import cone collapses all 17 `+PWG-3+` to `+ungraded+` (census
`+ungraded+` 24), and flipping one Lean leg to `+RECONCILED+` lifts that
obligation to `+PWG-2i+` — so they fire only if the published table really is
derived. Exercising the whole ladder: with both legs counting and current
receipts, the derivation returns `+PWG-1+`.
