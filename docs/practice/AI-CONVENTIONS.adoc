# AI Conventions (Authoritative Source)

All AI coding agents working in this repository MUST follow these rules.
Per-tool config files (.cursorrules, .clinerules, etc.) reference this document.

## Session Startup

1. Read `trope-checker_chora.deed` (the repo deed, at the root) FIRST: identity, status, ecosystem position, agent permissions and constraints.
2. Read `coordination.k9` for agent coordination (`project.deed_ref` names the deed).
3. Read `docs/governance/MAINTENANCE-CHECKLIST.adoc` and `docs/governance/SOFTWARE-DEVELOPMENT-APPROACH.adoc` for maintenance controls and execution order.

## Machine-Readable Record

The repo deed `trope-checker_chora.deed` at the root is the single machine-readable record.
A2ML is retired: NEVER create an `.a2ml` file (STATE, META, ECOSYSTEM, AGENTIC,
NEUROSYM, PLAYBOOK, ANCHOR or policy files) anywhere in the repository.

## Banned Patterns

| Language | Banned                              | Reason                    |
|----------|-------------------------------------|---------------------------|
| Idris2   | `believe_me`, `assert_total`        | Unsound escape hatches    |
| Haskell  | `unsafeCoerce`, `unsafePerformIO`   | Breaks type safety        |
| OCaml    | `Obj.magic`, `Obj.repr`, `Obj.obj`  | Unsafe casting            |
| Coq      | `Admitted`                          | Unproven assumption       |
| Lean     | `sorry`                             | Unproven assumption       |
| Rust     | `transmute` (unless FFI + SAFETY:)  | Unsound reinterpret       |

## Banned Languages

No TypeScript, ReScript, Deno, Node.js/npm or Python here; this repo's languages are the `:languages` list in `trope-checker_chora.deed`.
Go is banned too (use Rust).

## Container Standard

- Runtime: **Podman** (never Docker).
- File: **Containerfile** (never Dockerfile).
- Base images: `cgr.dev/chainguard/wolfi-base:latest` or `cgr.dev/chainguard/static:latest`.

## ABI/FFI Standard

- ABI definitions: **Idris2** with dependent types (`src/interface/Abi/`).
- FFI implementation: **Zig** with C ABI compatibility (`ffi/zig/`).
- Generated C headers: `generated/abi/`.

## Build System

Use `just` (Justfile) for all build, test, lint, and format tasks.
