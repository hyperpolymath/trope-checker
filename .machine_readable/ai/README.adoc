= AI Guidance Directory

Put AI-facing instructions in this folder.

Examples:

* `CLAUDE.md`
* `COPILOT.md`
* `GEMINI.md`
* `AI.djot`

Avoid scattering agent instruction files around the repo root.

Recommended machine read order:

* `trope-checker_chora.deed` (the repo deed, at the root)
* `coordination.k9` (agent coordination; `project.deed_ref` names the deed)
* `docs/practice/AI-CONVENTIONS.adoc`

The retired A2ML tree is frozen at https://github.com/hyperpolymath/trope-checker/tree/8f58d2409227b065fed01a898c02aba5fe134494/.machine_readable.
